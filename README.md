# FreshBite – Online Food Ordering Website

FreshBite is a responsive front-end web application for ordering food online. The project is developed using **HTML, CSS, and JavaScript** and demonstrates a complete basic food-ordering workflow from browsing food items to placing an order.

## 🌐 Live Website

**Live Demo:** https://freshbite-food-order.netlify.app/

## 📌 Project Overview

FreshBite is designed as a simple and user-friendly food ordering platform. Users can browse available food items, add products to a shopping cart, review their order, enter checkout details, and receive an order confirmation.

This project was created as a **Web Development / E-Commerce internship task** and focuses on practical front-end development concepts.

## 📁 Project Structure

```text
FreshBite/
│
├── index.html
├── cart.html
├── checkout.html
├── confirmation.html
├── styles.css
├── app.js
└── README.md
```

### File Description

- **`index.html`** – Main/home page containing the food ordering interface.
- **`cart.html`** – Displays selected food items and cart details.
- **`checkout.html`** – Provides the checkout/order form.
- **`confirmation.html`** – Displays the successful order confirmation.
- **`styles.css`** – Contains the complete styling and responsive design.
- **`app.js`** – Handles JavaScript functionality such as cart operations, quantities, totals, and user interactions.
- **`README.md`** – Project documentation.

## 🛒 How the Cart Works

1. The user selects a food item.
2. The item is added to the shopping cart.
3. The cart keeps track of selected products and quantities.
4. Users can increase or decrease quantities.
5. Items can also be removed.
6. The order total is calculated automatically.
7. The user proceeds to checkout after reviewing the cart.

## 🚀 How to Run the Project Locally

No backend server or database is required for the current front-end version.

### Method 1 – Using VS Code

1. Download or clone the project.
2. Extract the `FreshBite` folder if it is compressed.
3. Open the folder in **Visual Studio Code**.
4. Make sure all HTML, CSS, and JavaScript files are in the correct location.
5. Open `index.html` in a browser.

For a better development experience, you can use the **Live Server** extension in VS Code.

### Method 2 – Directly in a Browser

Double-click:

```text
index.html
```

The website will open in your default browser.
